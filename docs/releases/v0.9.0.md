# v0.9.0 - Gmail Communication Core

Release date: 2026-08-02

## Release Boundary

This release freezes the Phase 9C Gmail communication core after all 16 local go-live criteria passed against a real Gmail mailbox.

Validated flow:

```text
Lead 360
-> approved send
-> Gmail provider submission
-> sent-state reconciliation
-> threaded reply synchronization
-> exact lead and contact matching
-> CRM transition
-> active sequence exit
-> complete audit history
```

The release also includes attachment controls, scheduled delivery, suppression enforcement, unmatched inbound review, operational sequence enrollment, disconnect/reconnect handling, and reconciliation recovery.

## Deferred Operational Drill

An actual Google-side OAuth revocation was not triggered because it is destructive and requires another interactive consent. Provider refresh failures are sanitized, audited, and transition the mailbox to `EXPIRED` or `ERROR`; the adapter revoke path is covered by automated tests.
